# トイワホ製作所 (TOIWAHO WORKS) — エージェント・オフィス (`agents.html`)

Claude Codeのエージェント達が「トイワホ製作所」というWeb制作スタジオで働く様子を
可視化するページ。4つのモードがあります。

> 補足: このリポジトリ名 `kaido-site` は元々のクライアント「開土(KAIDO)」の
> ホテルサイトに由来します。エージェント可視化の会社は独立した架空スタジオ
> 「トイワホ製作所」です（KAIDOは登場する制作案件の一例にすぎません）。

## 🎬 デモモード（デフォルト）

台本による演出。`agents.html` をブラウザで開くだけで動きます。
「LP作って / バグ直して / 記事書いて / 新機能ちょうだい」の4ワークフロー。

## 🤖 AIモード — 会話と成果物を本物のOpusが生成

キャラ達の会話台本と成果物（LPのHTML・記事）を **claude-opus-4-8** がリアルタイム生成します。

1. 右上の ⚙️ 設定から Anthropic APIキー（`sk-ant-...`）を保存
2. 上部タブで「🤖 AI」に切替
3. 「温泉旅館のLP作って」などと指示

- 台本は構造化出力（JSON Schema）で1コール、成果物はストリーミング生成
- 生成中はオフィスの大型モニターにコードが流れます
- 完成するとプレビュー（iframe・JS無効サンドボックス）＋ダウンロードボタン
- **修正指示ループ**: 成果物モーダルの入力欄に「もっと和風に」等と入れて
  「↻ 修正を依頼」すると、担当キャラが前回の成果物＋指示でOpusに作り直させ、
  更新版を再納品します（何度でも）
- APIキーはブラウザの localStorage にのみ保存されます。**共有PCでは使用後に消去してください**

## 📡 LIVEモード — 実際のClaude Codeセッションを中継

ローカルで動いているClaude Codeのセッションログ
（`~/.claude/projects/<プロジェクト>/`）をブリッジサーバーが監視し、
実際のエージェント稼働を画面に反映します。

```bash
# リポジトリのルートで
node tools/agents-bridge.mjs            # このリポジトリのセッションを監視
node tools/agents-bridge.mjs ~/my-app   # 別プロジェクトを監視
PORT=9000 node tools/agents-bridge.mjs  # ポート変更
```

ブラウザで http://localhost:8787/agents.html を開き「📡 LIVE」タブへ。

| Claude Code側の出来事 | 画面上の演出 |
|---|---|
| アシスタントの発言 | PMの吹き出し＋ログ |
| Bash / Write / Edit | リクが作業 |
| Read / Grep / Glob | ソウが調査 |
| WebSearch / WebFetch | ナギが調べもの |
| サブエージェント起動 | 空いてるメンバーがタスク受領→自席で作業中に |
| 短時間に複数サブエージェント起動 | PMが会議テーブルで「並列でいくよ、手分けして！」と号令 |
| サブエージェント完了 | ✅を出して待機に戻る |
| TodoWrite / TaskCreate / TaskUpdate | 左上の**スプリントボード**にTODOが貼り出され、進捗(☐/🔨/✅)が更新される |
| ツールの失敗 (is_error) | 担当キャラが💦を出して震え、ログに赤字でエラー内容 |
| タスク完了 | PMが✅、ログに完了記録 |

- 完了検知はメインセッションのAgentツール結果（`agentId:`）＋12秒無活動タイムアウト
- 接続時に過去ログは再生しません（接続後の新しいイベントのみ演出）
- 依存パッケージなし（Node 18+）

## 🏢 会社モード — あなたが社長、案件ごとにAI社員を雇う

あなたが「社長」となり、案件ごとに **AI社員（Claude Code のヘッドレスプロセス）** を
雇って画面から指示するモードです。ローカルに `claude` CLI がインストールされている
必要があります（ブリッジが各案件を子プロセスとして起動します）。

- 使うブリッジは **LIVEモードと同じ** `node tools/agents-bridge.mjs`。SSE は同じ `/events`、
  案件操作は `/company/hire` `/company/instruct` `/company/stop` `/company/state` の各APIを使います。
- 上部タブで「🏢 会社」に切替 → 送信ボタンが「＋ 案件を雇う」に変わります。
- **雇用**: 案件名・作業フォルダ（絶対パス、省略可）・最初の指示・モデル（opus/sonnet/haiku）を入力。
  空いている社員（PM以外の5人）が会議テーブルへ歩いて「担当します！」と挨拶し、自席で作業を開始。
  デスク上に案件プレート（状態ドット: 金=作業中 / 緑=待機 / 灰=停止・終了）が表示されます。
- **カルテ**: 社員をクリックすると案件カルテが開き、受けている指示・最近の報告を確認でき、
  「✅承認・進めて」「📝報告して」「🔴一旦ストップ」や自由指示を送れます。
- 案件の進捗（発言・ツール実行・完了・エラー・終了）は吹き出し／ティッカー／統計HUDに反映されます。
- モードを離れても案件の子プロセスは止まりません（画面表示のみリセット。再入場で `/company/state` から復元）。

## オフィスの見た目

背景はイラスト1枚（`assets/images/agents/office-bg.jpg`）で、キャラの定位置は
画像内の椅子の位置にマッピングしています。別のオフィス画像に差し替える場合は
同名で置き換え、`agents.html` の `TEAM` の `desk` 座標（画像に対する%）を調整。

## LIVEモードの追加可視化

- **統計HUD**（右下）: ツール実行 / ファイル編集 / サブエージェント / フック / エラーの通算
- **変更ファイル**: Write/Edit されたファイルがスプリントボード下部に一覧表示
- **フック発動**: Stopフック等の実行が 🪝 とテロップ・ログで見える（失敗は赤字）

## 演出

- **効果音**（WebAudio、右上🔊でON/OFF・localStorage記憶）: 作業開始・完了ディン・
  完成ファンファーレ・エラーブザー
- **昼夜サイクル**: 3分周期でオフィスの照明が朝→昼→夕→夜とゆっくり変化
- **歩行アニメ**: キャラが移動方向を向いて足踏みしながら歩く
- **紙吹雪**: 完成時にcanvasで舞う
- **実況ティッカー**（LIVEモード限定）: ステージ上部にスポーツ中継風のテロップが
  下からスライドインし、ツール実行・サブエージェント起動/完了・エラーを実況。
  同一キャラの3・5連続実行でコンボ、通算10/25/50/100実行でマイルストーンを煽り、
  エラー時は待機中の同僚が「ドンマイ！」と声をかける。
- **ムード（表情差分）**: 頭の右横の表情マーク＋スプライトへのCSSフィルタで
  focused🔥（作業中）/ happy✨（完了・お祝い）/ troubled💧（エラー）/ tired💤
  （LIVEで45秒以上作業継続）を表現。ttl経過で自動的に通常表情へ戻る。

## モバイル対応

820px以下でトップバー2段＋縦積みレイアウト、520px以下でスプライト縮小。
横スクロールが出ないよう各パネルを画面幅に追従させています。

## キャラクター

6方向スプライト（`assets/images/agents/<name>-{front,front45,left,right,back,back45}.png`）。
移動方向に応じて向きが切り替わります。差し替えは同名PNGを置き換えるだけ。

| ID | 名前 | 役割 |
|---|---|---|
| pm | マネジャー | PM（指揮官） |
| design | アオイ | Designer |
| front | リク | Frontend |
| back | ハル | Backend |
| write | ナギ | Writer |
| qa | ソウ | QA（探偵） |
